# Modelagem híbrida para estimativa do fluxo de CO2 em cultivos de soja na Amazônia Legal

Este repositório organiza scripts, dados processados, documentação metodológica, figuras, resultados e materiais acadêmicos associados à tese de doutorado do Prof. David Lopes Maciel.

## Modelo oficial da tese

**Modelo Híbrido ISBA/SVAT-XGBoost para Determinação do Fluxo de CO2 em Cultivares de Soja na Amazônia Legal**

## Objetivo geral

Desenvolver e avaliar um modelo computacional híbrido para estimar o fluxo de CO2 em áreas cultivadas com soja, combinando dados EO-1 Hyperion, variáveis meteorológicas, estrutura biofísica baseada em ISBA/SVAT e correção residual por XGBoost.

## Organização

A organização atual usa o material já existente na pasta selecionada para versionamento Git local. Dados brutos pesados, arquivos geoespaciais grandes, compactados e credenciais devem permanecer fora do Git.
